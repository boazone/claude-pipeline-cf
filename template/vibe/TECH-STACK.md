## 0. The rule that decides everything

**One vendor for everything the running system calls: Cloudflare, on its free tiers.** A second
vendor of infrastructure is a decision card, not a default. A model provider behind AI Gateway is
the product, not infrastructure; GitHub holds the code and is not called by the running system.

## 1. The stack

| Layer | What | Why |
|---|---|---|
| Runtime | Cloudflare Workers, one Worker per environment | one deploy carries the whole system |
| API | Hono | small, typed, made for Workers |
| Database | D1 (SQLite), through drizzle-orm; migrations generated by drizzle-kit, applied by wrangler | free tier, no server, one file per environment |
<!-- {{#r2}} -->
| Files | R2, one private bucket per environment, keyed by prefix; served through the Worker | free egress; no public bucket, no CORS |
<!-- {{/r2}} -->
<!-- {{#ai}} -->
| Models | through AI Gateway, one gateway per environment; the provider keys are secrets | one place to see and cap spend |
<!-- {{/ai}} -->
| Web | Vite + React, built into `apps/web/dist` and served as the Worker's static assets | one origin, no CORS, no dev server in the topology |
| Format, lint | Biome | one tool, every file, on write |
| Tests | Vitest — the api inside workerd, the components in jsdom, the tools in Node; Playwright for the browser | the same runtime as production |
| Gates | `npm run verify` and gitleaks on every commit; a Claude Code guard | free: they run on the laptop |
| Deploys | Workers Builds on `env/prod`{{#qa}} and `env/qa`{{/qa}}; dev from the laptop | no CI minutes, no Actions |

## 3. Domains and paths

**One Worker serves everything, on one origin, split by path:**

| Path | What |
|---|---|
<!-- {{#multiapp}} -->
| `/` | the landing page |
<!-- {{#apps}} -->
| `/{{app}}/*` | the {{app}} app |
<!-- {{/apps}} -->
<!-- {{/multiapp}} -->
<!-- {{^multiapp}} -->
| `/` | the app |
<!-- {{/multiapp}} -->
| `/api/*` | the API |

**Every page path is in `PAGE_PATH`** (`../code/apps/api/src/index.ts`); any other path is a 404,
not the app's shell with a 200.

**Why paths and not subdomains.** One origin means one deploy, no CORS, one OAuth redirect URI per
environment, and a host-only session cookie.

**The session cookie, when sign-in lands:** no `domain` attribute ever; `httpOnly`, `Secure`,
`SameSite=Lax`, `Path=/`; prefixed `__Host-`. Each environment is its own hostname, so its own
cookie jar — a QA session cannot be presented to production. An environment difference is driven by
the `ENVIRONMENT` binding, never by a hostname check in application code.

<!-- {{#www}} -->
**Certificates are automatic.** Universal SSL covers the apex and one label (`qa.{{domain}}`,
`local.{{domain}}`); a second label would not be covered — stay flat.
<!-- {{/www}} -->
<!-- {{^www}} -->
**Certificates are automatic for `{{domain}}` only.** It is itself one label under its zone, and
Universal SSL covers the zone's apex and one label: `qa.{{domain}}` would be a second label, not
covered. `local.{{domain}}` needs none — it has no DNS record, and its certificate is mkcert's.
<!-- {{/www}} -->

## 4. Sign-in

Google, one OAuth client per environment, each with its own redirect URI
(`https://<host>/api/auth/callback/google`), the consent screen in *Testing* until a launch needs
verification. The clients exist (`dev/SETUP.md` S6); the code lands with the first story that needs
a signed-in user, behind its security card. On dev and the previews, a dev-only sign-in route —
present in dev's bundle and no other, behind Access and checked against Access's JWT — lets the
evaluator sign in without Google.
<!-- {{/google}} -->

<!-- {{#ai}} -->
## 5. The AI layer

Every model call goes through the environment's AI Gateway (`AI_GATEWAY_URL`); the provider key and
the gateway's token are secrets per environment, local carrying dev's. The prompts, when they land,
are the system's own — versioned rows, not strings in code.
<!-- {{/ai}} -->

<!-- {{#i18n}} -->
## 6. Languages and direction

Several languages and both directions, to `reference/i18n-and-rtl.md`: one typed dictionary per
language and no i18n library, `dir` and `lang` on `<html>` only, logical CSS properties only. The
compiler is the completeness check — a dictionary missing a key does not build.
<!-- {{/i18n}} -->
